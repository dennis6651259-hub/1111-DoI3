# DIC4 Goal

## 作業目標
以 DIC3 DietSense 為基礎，將專題提案改寫為可匯入 Overleaf 的英文學術論文草稿，重點完成 Abstract、Introduction、Related Work，保留修改前後版本，並以 OpenSpec 管理修稿規格及驗收。

## 教授要求來源
使用者提供的「教授要求.docx」列出：
- Overleaf 投稿 draft，Agent 加 Overleaf MCP 使用 LaTeX。
- 安裝 OpenSpec，處理 abstract、introduction、related。
- 提供 Overleaf paper 修改前後版本。
- GitHub 出現 OpenSpec，繳交 GitHub 與 goal/design/task.md。

以上為作業驗收依據。文件沒有指定投稿場域、篇幅或截止日。使用者已回覆沒有指定期刊／研討會與可編輯 Overleaf 專案；本次採通用 article 格式。

## 範圍與交付
- paper/before/main.tex：本次從 DIC3 整理的英文初稿 v0；不是既存 Overleaf 歷史版本。
- paper/after/main.tex：修訂論文 v1，包含三個指定章節及支撐的設計、評估、限制與結論。
- revision-notes.md：段落與研究設計修改理由。
- goal.md、design.md、task.md 與 openspec/：規格與可追蹤任務。
- validation/：實際 CLI、編譯與交付檢查紀錄。
- 可直接匯入 Overleaf 的兩份 ZIP 及完整作業 ZIP。

## 研究狀態邊界
500 筆資料、20 位成人試用、85% 命中、60% 節時、SUS 大於 70 都是原提案的計畫或目標。沒有結果資料，不寫成已完成實驗。論文草稿完成不等於系統實作完成。

## 完成條件
文字、來源、編譯、OpenSpec 和 GitHub 交付各自有證據。Overleaf 匯入及 MCP 實際呼叫需另有專案與連線證據；沒有證據時保持未完成，不以本機編譯代替。
