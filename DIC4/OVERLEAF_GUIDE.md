# Overleaf 操作與待補證據

## 目前狀態
已提供兩個獨立 LaTeX 專案，皆使用 main.tex。這是 Overleaf 可匯入來源，不表示已在 Overleaf 上建立專案。可用工具目前沒有 Overleaf MCP，因此尚無實際 MCP 呼叫或 Overleaf 專案連結。不可把 Codex 內建編譯紀錄稱為 Overleaf MCP 證據。

## 匯入步驟
1. 登入自己的 Overleaf，選 New Project → Upload Project。
2. 上傳 DIC4_Overleaf_Before.zip，將專案命名 DietSense DIC4 Before。
3. 選 main.tex 為 Main document，Compiler 選 pdfLaTeX，按 Recompile。
4. 對 DIC4_Overleaf_After.zip 重複操作，命名 DietSense DIC4 After。
5. 保存兩個專案的唯讀分享連結及首頁截圖；截圖包含專案名、版本日期與編譯預覽。
6. 在課程允許的 Agent 環境連接可信任的 Overleaf MCP。採服務所支援的授權方式；不要把 token 或登入 cookie 放入 GitHub。
7. 經 MCP 讀取 main.tex，核對當前專案。可先做真實且可檢查的修改，例如調整 RQ2 文句；重新編譯，保留修訂前後 diff 與工具執行記錄。
8. 將實際連結及已遮去敏感資訊的證據補入 validation/overleaf-evidence.md。只有在實際執行後才勾選 task.md 對應項目。
