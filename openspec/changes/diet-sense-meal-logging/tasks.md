## 1. 資料與測試基礎

- [ ] 1.1 建立食藥署與 USDA 版本化資料，檢查基準、單位、生熟與空值。對應 nutrition-estimation。
- [ ] 1.2 建立臺式配方及 500 筆描述的標註規格。按店家／菜系分組並鎖定測試集。對應 nutrition-estimation。

## 2. 對話與估算

- [ ] 2.1 建立繁中輸入與結構化意圖抽取，測試牛肉麵加蛋、半湯與修改語句。對應 meal-logging、nutrition-estimation。
- [ ] 2.2 實作資料檢索、固定快照降級與數值工具。驗收 150 g × 200 kcal / 100 g = 300 kcal。對應 nutrition-estimation。
- [ ] 2.3 實作兩輪澄清、略過、區間與未估。測試逾時、來源缺漏及上下界順序。對應 nutrition-estimation。

## 3. 日誌、分析與安全

- [ ] 3.1 實作草稿版本、確認去重、擁有者驗證與刪除。測試並行重送與舊版本拒絕。對應 meal-logging。
- [ ] 3.2 實作日期摘要與可選 TDEE，測試未估筆數、缺活動欄位、刪除後重算。對應 intake-analysis。
- [ ] 3.3 實作風險前後檢查與保守降級。測試 900 kcal、補償、孕哺、未成年及規則載入失敗。對應 dietary-safety。

## 4. 驗收與評估

- [ ] 4.1 執行至少 30 個 Agent 情境，逐例保留輸入、版本、期望、實際狀態與差異。對應四項能力。
- [ ] 4.2 比較手動基線與兩項消融，報告熱量命中、MAE、區間寬度與覆蓋率。
- [ ] 4.3 完成 20 位成人七日試用並分析配對時間、完成率及 SUS。
- [ ] 4.4 通過規格與實作核對後才執行 archive。
